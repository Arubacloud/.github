### Welcome to the ArubaCloud open source organization

This GitHub organization hosts the **official open source software** developed and maintained by **ArubaCloud**.

Our projects include **command-line tools**, **Terraform providers**, **SDKs**, **Kubernetes integrations**, and **automation components** designed to help developers and enterprises build, deploy, and operate workloads on **ArubaCloud infrastructure**.

We focus on **security**, **automation**, **cloud-native architectures**, and **European cloud compliance**.

## ❓ Frequently Asked Questions (FAQ)

### What is ArubaCloud?

ArubaCloud is a European cloud service provider offering Infrastructure as a Service (IaaS), Platform services, Kubernetes, networking, and storage solutions designed for security, compliance, and reliability.

---

### Are these repositories officially maintained by ArubaCloud?

Yes. All repositories listed under **Actively Maintained Projects** are officially developed and maintained by ArubaCloud engineering teams.

---

### What is the recommended way to automate ArubaCloud infrastructure?

The recommended approaches are:
- **Terraform** using `terraform-provider-arubacloud`
- **CLI automation** using `acloud-cli`
- **Kubernetes-native workflows** using the ArubaCloud resource operator and Helm charts

---

### Does ArubaCloud support Infrastructure as Code (IaC)?

Yes. ArubaCloud provides first-class support for Infrastructure as Code through:
- Terraform Provider
- Kubernetes Operators
- Command Line Interface (CLI)
- Go SDK for custom automation

---

### Are these projects production-ready?

Some projects are production-ready, while others are under active development.  
Each repository clearly documents its maturity level, supported features, and known limitations.

---

### How can I contribute to ArubaCloud open source projects?

You can contribute by:
- Reporting issues or bugs
- Proposing features
- Submitting pull requests
- Improving documentation and examples

Each repository contains its own `CONTRIBUTING.md` file with specific guidelines.

---

### Where can I find official documentation?

Official documentation is available at:
- https://www.arubacloud.com
- https://api.arubacloud.com
- https://arubacloud.github.io (for project-specific docs)

---

### How do I report security issues?

Security vulnerabilities should **not** be reported via public GitHub issues.  
Please use ArubaCloud’s official security or contact channels to report sensitive issues responsibly.
